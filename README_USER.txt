[FA] راهنمای سریع راه‌اندازی و استفاده:
--------------------------------------------------
۱. نحوه اجرا:
   - برای اجرای بدون پنجره سیاه، روی "Hemoglyph.vbs" دابل‌کلیک کنید.
   - یا برای ساخت آیکون اختصاصی روی دسکتاپ، فایل "Create_Desktop_Shortcut.bat" را اجرا نمایید.

۲. فعال‌سازی لایسنس (در اولین اجرا):
   - شناسه سخت‌افزاری اختصاصی (Machine ID) را کپی کرده و به ایمیل sobahramisamani@gmail.com ارسال فرمایید.
   - کلید لایسنس دریافتی را وارد کرده و دکمه Activate را بزنید.

۳. تشکیل پرونده بیمار:
   - سن، جنسیت، قد، وزن و وضعیت بارداری را وارد کنید (جهت فعال شدن محافظ‌های فیزیولوژیک).

۴. ثبت نتایج آزمایش:
   - به روش دستی (Manual Entry) با جستجوی پارامترها (مانند FBS, ALT, eGFR, Troponin).
   - یا با بارگذاری فایل عکس/پی‌دی‌اف آزمایش در بخش Upload (پردازش خودکار OCR).

۵. مشاهده تحلیل بالینی و مدل‌های ریسک:
   - مشاهده همزمان ریسک قلبی-عروقی (AHA PREVENT)، فیبروز کبدی (FIB-4)، ریسک نارسایی کلیه (KFRE)،
     تشخیص‌های افتراقی رتبه‌بندی شده و آزمایش‌های تاییدی پیشنهادی بر اساس ۳۳,۸۷۵ قانون بالینی معتبر.

۶. حفظ ۱۰۰٪ محرمانگی:
   - نرم‌افزار کاملاً آفلاین بوده و هیچ اطلاعاتی از بیمار به اینترنت ارسال نمی‌شود.


[EN] Quick Start & Clinical Instructions:
--------------------------------------------------
1. How to Launch:
   - Double-click "Hemoglyph.vbs" for silent, pure GUI launch.
   - Or run "Create_Desktop_Shortcut.bat" to place a desktop shortcut.

2. License Activation:
   - Copy your unique Machine ID and email it to sobahramisamani@gmail.com.
   - Paste the generated RSA-4096 license token and activate.

3. Clinical Workflow:
   - Set Patient Profile (Age, Sex, Height, Weight, Pregnancy Status).
   - Input Lab Values manually or upload lab report via OCR.
   - Review multi-organ synthesis, 100 validated risk models, differential diagnoses,
     and evidence-based recommendations (KDIGO, ADA, ACC/AHA).

4. Zero Cloud Transmission:
   - 100% On-Device, Air-Gapped execution ensuring complete patient confidentiality.
