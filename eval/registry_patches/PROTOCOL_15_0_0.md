# Registry 15.0.0 — provenance-and-fidelity release (protocol, written 2026-10-27 before any change)

Trigger: the activity-guided audit (`eval/provenance/RESULTS.md`): 364 active rules, 73 % generated templates with false provenance, 92 % of a fresh sample unresolvable, topic-mismatched citations, population-gate and boundary defects in the hot core.

Principles (standing): changes are guideline-fidelity changes decided from the rule text and its source, never from benchmark labels; no weight, prior or fusion parameter is touched; no rule is written for a missed case; v7 and registry 14.1.0 stay frozen for the paper; 15.0.0 is a development release evaluated once, after all edits, and reported whatever the direction of change.

## Change classes (closed list)

- **R1 Template provenance.** Every executable rule attached to a `biomarker_pattern` (`co_*`) entity is re-attributed from `who_essential_lab_2024` to a new source record `generated_pair_pattern` (kind: generated two-analyte co-occurrence template; no document), status `generated_pattern_not_guideline`, `evidence_tier: none`. Executable flag and logic unchanged.
- **R2 Retirement** (`executable: false`, status `retired_v15_0_<class>`), applied to active-core rules and to any rule outside the core that matches the same class by exact pattern:
  - R2a *nonspecific single marker for a specific disease*: one routine analyte at or near a reference limit asserting a specific (usually rare) disease, with no guideline stating that criterion (CK → McArdle/Pompe/ALS/tetanus/trichinellosis/rhabdomyosarcoma/polymyositis/serotonin syndrome/NMS; lactate → cerebral malaria/CO poisoning/Leigh/MELAS/beriberi; electrolytes → pyloric stenosis/cystic fibrosis/SIADH-sodium/Addison-sodium; ALP/WBC/bilirubin → hepatic abscess/cholangitis/Paget; platelets → Gaucher/NEC; TSH → Down syndrome; glucose → galactosemia; calcium → renal cell carcinoma; lipase/amylase → mumps/salivary tumour; albumin → PEM/kwashiorkor/hepatic encephalopathy; ALT → celiac/pancreatitis; cholesterol → decompensated HF; CRP/WBC → UTI/gastroenteritis/cellulitis/CAP; HbA1c → peripheral arterial disease).
  - R2b *logically defective or contradicting its own source*: asserts a disease from a normal value or an unrelated analyte (prediabetes from HbA1c < 6.5 %; HHS from FPG ≥ 126; type 1 diabetes / LADA from glucose or HbA1c alone; euglycaemic DKA without a ketone leaf; thrombocytosis attributed to iron deficiency or haemochromatosis; frailty from albumin + haemoglobin; troponin → takotsubo/cardiorenal; MCV > 100 as a *diagnostic criterion* for alcoholic liver pattern; clozapine agranulocytosis from WBC < 4 and ANC < 1.8; fixed creatinine thresholds attributed to KDIGO AKI, which defines AKI by change from baseline — the curated chronicity-undetermined rule remains).
  - R2c *duplicate with non-source thresholds*: `_f13_3` sex-scaled variants whose numbers (11.56, 10.67, 1.02 …) appear in no source while the parent rule exists.
- **R3 Re-sourcing with verification.** For active rules whose threshold is stated in a reachable authoritative document, the source record gets a working locator (DOI, PubMed Central deposit or official PDF) and the rule gets `provenance.verified_quote`, `provenance.verified_locator`, `provenance.verified_on`. Verification = the threshold and analyte appear together in the retrieved text (or a figure read by the rater); otherwise nothing is written.
- **R4 Reference-interval convention.** Findings that are reference-limit conventions (hypo/hypernatraemia, hypo/hyperkalaemia, hypomagnesaemia, hypophosphataemia, hyperchloraemia, leukocytosis, neutrophilia, elevated INR, hyperbilirubinaemia, acid–base definitions, pancytopenia) lose their topic-mismatched citation and are attributed to an explicit record `reference_interval_convention` (kind: laboratory reference-interval convention, assay-dependent; no single document), unless R3 finds a guideline statement (ESE 2014 hyponatraemia, KDIGO 2020 potassium).
- **R5 Logic corrections with a quoted source** (closed list; each carries the quote): WHO 2024 child haemoglobin rule restricted to children (`age_groups` child only; 115 g/L applies to 5–11 years); HbA1c prediabetes screening `> 5.7` → `>= 5.7 and <= 6.4`; elevated-HbA1c finding `> 5.7` → `>= 5.7`; fasting hypoglycaemia `< 55` → `< 54 mg/dL` (ADA level 2); rhabdomyolysis `>= 1000` → `> 1000 U/L`; ITP isolated-thrombocytopenia rule's platelet leaf unchanged but re-sourced to the 2009 international terminology paper.
- **R6 Source records.** Broken locators replaced by verified ones (WHO anaemia 2024, ADA 2026 Section 2, Sepsis-3, Surviving Sepsis 2021, KDIGO 2012/2024 PDFs, ADA/EASD 2024, BSG 2021, ACR/EULAR 2015, ESE 2014, KDIGO 2020 potassium, Cairo–Bishop 2004, Rodeghiero 2009); `last_verified_on` set only where retrieval succeeded today.

## Gate (one run after all edits; results reported verbatim)

1. `pytest` suite (705 tests) and the hard batteries/healthy sweep must not regress.
2. eICU-CRD demo, labs only, `--encounter icu`, current engine (v8.2), registry 14.2.0 vs 15.0.0: flat recall@1/3/5/10, two-tier, per-group deltas, top-5 unsupported-assertion rate (verifier proxy). Expected direction: AKI recall down (R2b), precision up, template entities out of top-5; any change is reported.
3. NHANES 2017–18 (1,000 adults): diabetes/CKD/anaemia AUROC within 0.03 of 14.2.0.
4. Activity log re-run on the same panels: new active-core size and provenance class table.

Nothing in the main-text results changes; 15.0.0 is reported in Supplementary Note 15 as the post-audit development release.
