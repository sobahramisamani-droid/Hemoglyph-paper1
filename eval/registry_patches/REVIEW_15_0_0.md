## 4. Protocol deviation

`acute_kidney_injury_v1` (fixed creatinine >1.3 / eGFR <60) was scheduled for retirement under R2b. The pytest gate produced 6 regressions (e.g. creatinine 4.4 mg/dL, BUN 71, K 5.9 in a single panel no longer ranked AKI in the top 10) because the ESL layer treats this rule as the single-panel renal-failure signal and already caps it as 'chronicity undetermined'. The retirement was reversed; the rule is re-sourced to KDIGO 2012 with the definition quote, `evidence_tier = single_panel_surrogate`, and an explicit note that KDIGO defines AKI by creatinine change. Its sibling `acute_kidney_injury_v1_f13_3` (thresholds 1.1 / 1.02, no source) stays retired.
