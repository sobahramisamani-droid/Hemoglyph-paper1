# Verified consensus arm (engine + verifier-filtered LLM) — protocol, committed before any computation

Date: 2026-10-27. Results file does not exist at commit time.

## Question
Does a fixed, parameter-free fusion of the frozen engine's ranking with the LLM entries that the engine's
own criteria support (eval/verifier) exceed both single systems on the 400 blind eICU stays, while keeping
the unsupported-assertion rate at or below the engine's?

## Inputs (existing; no new LLM call; frozen v7 untouched)
- Engine v7 group ranking per stay (`per_stay_v7.json.gz`, field gr).
- LLM 400 blind readings and the per-entry verdicts of eval/verifier (verdict file is regenerated by the
  verifier script, not edited).
- Labels and synonym map as in Table 5 / Note 2; criteria as in eval/verifier.

## Fusion rule (single, fixed; no parameter is tuned or swept)
B' = LLM entries with verdict "supported" only (contradicted, absent, not_verifiable and out-of-vocabulary
entries are discarded), in their original order, mapped to groups -> rank_B'(g).
Primary arm F (reciprocal-rank fusion, k = 0):
    score(g) = 1/rank_A(g) + 1/rank_B'(g), missing rank contributes 0;
    ties: lower engine rank first, then lower B' rank.
Secondary arm G (append): engine list A, followed by B' groups absent from A, in B' order.
Both rules were written down here before the script existed.

## Metrics (existing definitions only)
recall@1/3/5/10 against clinician labels (596; b8 rule), stay-clustered bootstrap (4,000) for the paired
differences F - engine and F - LLM; top-5 unsupported-assertion rate of F through the same verifier;
share of F's top-5 entries that are traceable to an engine rule (should be 100 % by construction: every
B' entry is admitted only because a criterion held, and the criterion is the engine's).

## Registered predictions
recall@5 of F 63-67 % (engine 60.7, LLM 59.6); recall@1 of F >= 29 %; F top-5 unsupported <= engine's
15.3 %; G within 1 point of F at k = 5. If F < 62 % the systems are reported as not complementary.

## Scope limits
NHANES healthy-adult specificity is not re-scored (the verifier's criteria do not cover the B5
conditions iron deficiency and hypercholesterolaemia); the arm depends on an LLM and is reported as an
optional arm, not as the system. No threshold, weight or map is changed after seeing results.
