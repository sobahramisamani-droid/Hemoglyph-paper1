# Hemoglyph v8 — evidence triage of the 12-item improvement roadmap (2026-10-26)

Rule applied: *first evidence, then change*. Every item was tested against the frozen v7 artefacts
(`eval/results/eicu_demo/per_stay_v7.json.gz`, ablation tables, PhysioNet 2019 subsets) before any code was
touched. Verdicts: **SUPPORTED → implemented**, **PARTLY → implemented in a reduced, principled form**,
**REFUTED → not implemented (data contradict the expected gain)**, **DEFERRED → needs resources the agent
does not have (clinician, credentialed data) or is a product-layer item**.

## What v8 changes in the engine (`analyse_gidlines.py`)
1. `meld_na` derived pattern (MELD / MELD-Na, OPTN formula with Na clamp 125–137, bilirubin/INR/creatinine floors at 1, creatinine cap 4, score clamp 6–40; three-month mortality bands; transplant-referral note ≥ 15).
2. `plr_high` derived pattern (platelets / absolute lymphocytes > 200; `significance="low"`, never supports a diagnosis).
3. `confidence_band` + `concise` on each `differential_diagnosis` entry (presentation only).
No fusion weight, threshold, registry logic or ranking rule changed.

## Gate (must pass before v8 replaces v7 as the development engine)
`eval/results/gate_v8/run_gate_v8.sh`: hard batteries (expect 151/151, 124/124, 77/78), healthy sweep 0/1000,
perturbation ≥ 753/755, probes, pytest 689, eICU labs-only non-inferiority (flat@5 ≥ 60.8 − 0.5, two-tier@5 ≥ 71.9 − 0.5).
Frozen v7 results are not modified; v8 is a development candidate until a new freeze amendment.
